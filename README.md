## Featured project

### AI-Powered Student Study Assistant
A study assistant web app combining a machine learning difficulty-prediction model (TF-IDF + Logistic Regression) with a prompt engineering lab that compares five prompting techniques side by side. Also includes an auto note/quiz generator, a day-wise study planner, and an activity dashboard, with both an offline demo mode and a live LLM API mode.

**Stack:** Python · Streamlit · Scikit-learn · Pandas · NumPy · SQLite
